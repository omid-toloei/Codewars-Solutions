# Mirror, mirror, on the wall...

My solution to the **"Mirror, mirror, on the wall..."** kata from Codewars.

## 📌 Challenge

* **Platform:** Codewars
* **Rank:** 7 kyu
* **Topics:** Arrays, Fundamentals

## 💡 How It Works

The function takes an array of numbers and creates a mirrored version of it.

* The array is sorted in ascending order.
* The sorted array is reversed to create the first half of the result.
* Each number is added to the result.
* Every number except the first one is added twice, creating the mirrored pattern.

For example:

```text
[1, 2, 3] → [1, 2, 3, 2, 1]
```
