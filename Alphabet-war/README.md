# Alphabet War

My solution to the **"Alphabet War"** kata from Codewars.

## 📌 Challenge

* **Platform:** Codewars
* **Rank:** 7 kyu
* **Topics:** Strings, Fundamentals

## 💡 How It Works

The function takes a string and calculates the total power of the letters for the left and right sides.

* Each special letter has a specific power.
* The function finds each letter and determines which side it belongs to.
* The power of each letter is added to the corresponding side.
* The two total powers are compared to determine the winner.

For example:

```text
"z" → "Right side wins!"
"wwwwwwz" → "Left side wins!"
```
