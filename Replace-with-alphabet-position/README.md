# Replace With Alphabet Position

My solution to the **"Replace With Alphabet Position"** kata from Codewars.

## 📌 Challenge

* **Platform:** Codewars
* **Rank:** 6 kyu
* **Topics:** Strings, Fundamentals

## 💡 How It Works

The function converts each letter in the input text to its position in the alphabet.

* Uppercase letters are converted to lowercase.
* Non-alphabetic characters are removed.
* Each remaining letter is replaced with its alphabet position (`a = 1`, `b = 2`, ..., `z = 26`).
* The positions are returned as a space-separated string.

For example:

```text
"abc" → "1 2 3"
"Hello" → "8 5 12 12 15"
```
