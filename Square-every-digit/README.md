# Square Every Digit

My solution to the **"Square Every Digit"** kata from Codewars.

## 📌 Challenge

* **Platform:** Codewars
* **Rank:** 7 kyu
* **Topics:** Fundamentals, Strings, Numbers

## 💡 How It Works

The function takes a number and squares each of its digits.

* The number is converted to a string.
* Each digit is converted back to a number.
* Each digit is squared.
* The squared digits are joined together to create the final result.

For example:

```text
9119 → 811181
```
